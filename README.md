# Skill Swap

Skill Swap is a peer-to-peer platform where college students exchange skills. One student teaches a subject while the other pays cash or trades an hour of their own expertise. Students create a public profile with their name, bio, skills, and hourly rate; seekers find them through a keyword search and message before booking a session.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** PostgreSQL with Sequelize ORM
- **Caching:** Redis
- **Real-time:** WebSockets
- **Testing / CI:** GitHub Actions
